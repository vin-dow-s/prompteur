# Demo script

Every heading opens a section, and every row of a table under it is one
sentence: what you say on the left, what you show on the right. Anything else
in the file, like this paragraph, is ignored, so a script can carry notes.

## Welcome · the band

| Say | Show |
|---|---|
| Hi, this is Prompteur, a teleprompter that sits right under the camera. | Look at the band, not at the screen |
| It floats above every window, even a browser in full screen. | Switch to a full-screen app |
| And it never takes the keyboard away from the app you are showing. | Type something in the browser |

## Moving through a script · shortcuts

| Say | Show |
|---|---|
| Tap Option on its own to go to the next sentence. | ⌥ |
| Option and left arrow goes back one sentence. | ⌥← |
| Option with the down or up arrow jumps to the next or previous section. | ⌥↓ ⌥↑ |
| Drag the band wherever you like, and the little cross closes it. | Drag the band |

## Recording · screenshots and screen recordings

| Say | Show |
|---|---|
| By default the band stays out of your screenshots and screen recordings. | Start a screen recording |
| Press Option V when you want it in the picture, for a demo like this one. | ⌥V |
| ! A sentence starting with an exclamation mark is shown in yellow. | Use it for a line you must not forget |

## Your own script · ~/Prompteur/script.md

| Say | Show |
|---|---|
| To use your own script, save it as script dot md in a folder named Prompteur in your home folder. | ~/Prompteur/script.md |
| It is a Markdown table like this one: what you say on the left, what you show on the right. | Open examples/demo.md |
| The band picks it up as soon as it is saved, and every later edit too. | Edit the file and save |
| You can also ask an AI agent to write it there for you. | See the README |
